# 🛒 Blinkit Sales Analysis – Python, Excel, PostgreSQL & Power BI

## 📊 Project Overview

This is an end-to-end **Blinkit Sales Analysis** project using **Python, Excel, PostgreSQL, and Power BI**.

The project analyzes Blinkit grocery sales data to understand sales performance, item types, fat content, outlet characteristics, outlet locations, outlet sizes, ratings, and key business KPIs.

Python is used for data analysis and visualization, Excel is used for data preparation, pivot analysis and dashboarding, PostgreSQL is used for SQL-based business analysis, and Power BI is used to create an interactive sales dashboard.

## 🎯 Objectives

- Analyze Blinkit sales and business performance.
- Explore and clean the grocery sales dataset using Python.
- Perform pivot-based analysis and dashboarding in Excel.
- Perform business analysis using PostgreSQL and SQL.
- Analyze sales by item type and fat content.
- Compare outlet size, location, establishment year, and outlet type.
- Analyze average sales, number of items, ratings, and item visibility.
- Build interactive dashboards using Excel and Power BI.
